# Visualization Tools for Block DAG Analysis

This directory contains Python scripts for visualizing and analyzing the output from the `block-dag-analyzer` tool.

## Setup

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Or if you prefer using a virtual environment:

```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Scripts

### 1. `efficiency_ratio_plot.py`
Analyzes the efficiency ratio of block parallelization using the formula:
`max(critical_path_cus, total_cus/num_chains) / max_dist_cus`

**Usage:**
```bash
python efficiency_ratio_plot.py data.csv
python efficiency_ratio_plot.py data.csv --output plots/
python efficiency_ratio_plot.py data.csv --stats-only
```

**Outputs:**
- Histogram of efficiency ratios
- Box plot distribution
- Cumulative distribution curve
- Scatter plot vs block size
- Detailed statistics and constraint analysis

### 2. `gantt_chart.py`
Creates Gantt chart visualizations showing transaction execution timelines across chains.

**Usage:**
```bash
python gantt_chart.py dag.csv
python gantt_chart.py dag.csv --output plots/
python gantt_chart.py dag.csv --detailed  # Show transaction labels
```

**Features:**
- Timeline visualization of transaction execution
- critical path transactions highlighted in red
- Chain utilization statistics
- Basic and detailed modes

### 3. `critical_path_distribution.py`
Analyzes the distribution of critical path CUs across blocks.

**Usage:**
```bash
python critical_path_distribution.py data.csv
python critical_path_distribution.py data.csv --output plots/
python critical_path_distribution.py data.csv --stats-only
```

**Features:**
- Histogram of critical path CU values
- Box plot showing quartiles and outliers
- Cumulative distribution curve with percentiles
- Log-scale distribution for better visibility
- Detailed statistics and size categorization
- Critical path ratio analysis

### 4. `block_limit_analysis.py`
Analyzes what percentage of blocks would be invalid under various CU limits.

**Usage:**
```bash
python block_limit_analysis.py data.csv
python block_limit_analysis.py data.csv --limit 30000000  # 30M CU limit
python block_limit_analysis.py data.csv --output plots/
```

**Outputs:**
- Percentage of blocks exceeding limits
- Analysis across multiple thresholds (20M-50M CUs)
- Worst offending blocks
- Impact assessment statistics

### 5. `visualizer.py`
General-purpose visualization tool with multiple chart types.

**Usage:**
```bash
python visualizer.py data.csv --plot-type chains
python visualizer.py data.csv --plot-type timeline
python visualizer.py data.csv --plot-type efficiency
```

**Plot Types:**
- `chains`: Chain utilization bar charts
- `timeline`: Execution timeline
- `efficiency`: Efficiency metrics dashboard

## Data Format

The scripts expect CSV files generated by `block-dag-analyzer`:

**Block Summary CSV** (for most scripts):
- `slot,total_cus,max_dist_cus,critical_path_cus,chain0_cus,chain1_cus,chain2_cus,chain3_cus,empty_cus`

**DAG Timeline CSV** (for Gantt charts):
- `chain,start_cus,end_cus,on_critical_path`

## Examples

```bash
# Generate data with the Rust tool
cargo run --release -- range 285000000 285000100 --chains 4 > data.csv

# Generate DAG timeline data
cargo run --release -- range 285000000 285000100 --chains 4 --dag-csv > dag.csv

# Create efficiency analysis
python visualization/efficiency_ratio_plot.py data.csv

# Create critical path distribution analysis
python visualization/critical_path_distribution.py data.csv

# Create Gantt chart
python visualization/gantt_chart.py dag.csv --detailed

# Analyze block limits
python visualization/block_limit_analysis.py data.csv --limit 25000000
```
